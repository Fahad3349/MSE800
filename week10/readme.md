# User Account Management System

## Description

This is a simple Python application that allows users to:

* Register an account
* Login to the system
* View their profile
* Reset a forgotten password

The system stores user information in an SQLite database and uses password hashing for security.

## Features

* User Registration
* User Login
* Forgot Password
* View Profile
* Secure Password Storage

## Technologies Used

* Python
* SQLite3
* Hashlib
